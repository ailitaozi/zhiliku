# GitHub 使用速查卡

整理日期：2026-11-10

## 一句话

GitHub 是一个云端文件夹，每次改动自动留一份存档，随时能找回。

## 老大只需要说人话

- 「看看志莉库里有什么」
- 「把 D:\...\某文件 传到志莉库」
- 「改一下志莉库里 xxx 的第二段」
- 「列一下最近的改动」
- 「把 xxx 恢复到上一次的版本」

## 四个概念

- 仓库 repo：一个项目文件夹
- 提交 commit：一次存档
- 分支 branch：平行开一条改动线
- PR：把分支的改动申请合并回主分支
